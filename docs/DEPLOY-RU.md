# Запуск на Vercel — пошагово

## 1. Создай Supabase

1. Открой https://supabase.com/dashboard и войди.
2. Нажми **New project**, выбери бесплатную организацию / Free plan.
3. Название, например `miss-saigon`. Пароль базы сохрани у себя. В чат его отправлять не требуется.
4. Выбери подходящий регион, например Frankfurt для команды в Австрии.
5. Дождись готовности проекта.

## 2. Подготовь базу и закрытое хранилище

1. В проекте Supabase открой **SQL Editor → New query**.
2. В GitHub открой `supabase/setup.sql`, затем **Raw / Copy raw file**.
3. Вставь весь SQL в редактор Supabase и нажми **Run**.
4. Скрипт создаст таблицы, серверные функции и приватный bucket `menu-originals`. Повторный запуск не удаляет меню и прогресс.

Если переносишь текущий прогресс, выполни **отдельный приватный SQL-файл импорта сейчас**, до первого входа в новый учебный интерфейс. В публичном GitHub этого файла нет. Без импорта приложение начнёт с исходного набора меню и нового прогресса. Подробнее: `docs/MIGRATION-RU.md`.

## 3. Найди параметры Supabase

В окне **Connect** либо **Project Settings → API / API Keys** найди:

- **Project URL** вида `https://<project-ref>.supabase.co` → `SUPABASE_URL`.
- **Secret key** (`sb_secret_...`) либо **legacy service_role key** → `SUPABASE_SECRET_KEY`.

Нужен именно серверный ключ. `anon` / `publishable` для нашего сервера не подойдут. Ключ вводится только в Vercel, не в исходный код и не в чат.

## 4. Импортируй репозиторий в Vercel

1. Vercel → **Add New → Project**.
2. Выбери репозиторий `ucrystalcastles/Miss-saigon` → **Import**.
3. **Framework Preset: Other**.
4. **Root Directory:** корень репозитория.
5. Build Command: `npm run build`.
6. Output Directory: `dist`.
7. Install Command: по умолчанию / `npm ci`.
8. В **Environment Variables** добавь:

| Имя | Значение |
| --- | --- |
| `SUPABASE_URL` | Project URL из Supabase |
| `SUPABASE_SECRET_KEY` | Secret / service_role ключ из Supabase |
| `APP_PIN` | Твой выбранный четырёхзначный PIN |

Для сохранения прежнего PIN просто введи прежнее значение в `APP_PIN`. Сам PIN не записан в инструкции или исходном коде.

Укажи Production. Для Preview лучше создать отдельный проект Supabase. Ключ и PIN пометь как Sensitive, если интерфейс предлагает этот флажок.

9. Нажми **Deploy**.
10. После завершения открой адрес `*.vercel.app` и введи PIN. Аккаунт ChatGPT не требуется.

Если настройки добавлены уже после первого деплоя: **Deployments → последний деплой → Redeploy**.

## 5. Что проверить после запуска

- Неверный PIN отклоняется, верный открывает меню.
- Все напитки, фотографии и классы вин видны.
- Короткий урок завершается, ошибки красные, правильные ответы зелёные.
- После обновления страницы записанный прогресс остаётся.
- Загружается тестовый TXT/CSV; его оригинал появляется в Supabase Storage → `menu-originals`.
- Выход закрывает доступ к каталогу.
- Справочник показывает Wikipedia внутри приложения.

## Если есть ошибка

- Сообщение `Database is not configured`: проверь Environment Variables и выполни Redeploy.
- `Database request failed`: проверь, что выполнен весь `setup.sql` и указан серверный ключ нужного проекта.
- Нет импортированного прогресса: приватный импорт должен выполняться в том же проекте Supabase до первого входа. Защитный импорт не перезаписывает уже инициализированный каталог.
- Не загружается оригинал: проверь bucket `menu-originals`, настройки из `setup.sql` и размер файла (≤15 МБ).

Публичный репозиторий не означает публичную базу: доступ к её функциям открыт только серверу с серверным ключом. Сам прототип пока использует общий PIN, включая управление меню, и общий прогресс.
